# Administrative-record modules

This directory holds the repository's administrative-record participation modules — the
public-record documents of the project's own participation in the Form HUD-27061 renewal
docket, kept separate from the research appendices because they are evidence of
participation, not support for the article's empirical findings.

## Modules

| Module | Contents |
|---|---|
| [`pra_comment_2026/`](pra_comment_2026/) | The author's as-filed individual-capacity comment on the 2026 Form HUD-27061 renewal (Comment No. HUD-2006-0214-0011): the as-filed text, a redacted PDF, the regulations.gov filing and posting confirmations, a redacted API record, OIRA status pulls, and a part-by-part crosswalk to the Note. See that module's README for the file inventory. |

Later stages of the same docket (for example, a 30-day OMB-stage record) will be added as
sibling modules rather than merged into the filed-comment module, so each filing's record
stays immutable as filed.

## What these modules are and are not

They are evidence of the fact and content of the identified filings, preserved as filed.
They are not evidence that HUD accepted any filing's legal or factual propositions, not
support for the article's empirical findings, and not a standing predicate. The Note's
own disclosure of the filing is contextual only.
