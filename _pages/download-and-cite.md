# Download and Cite

Where to read the manuscript, how to cite it, and what the reuse terms are.

## The manuscript

Nicholas Gill, *Duty Without Data: Disability Fair Housing and the Record-Dependent Right*,
forthcoming, Arizona Law Review (2026).

- [Read the manuscript](https://github.com/NickGillArizona/Duty-Without-Data/blob/main/manuscript/Duty_Without_Data.md)
  (Markdown, rendered in the browser; footnotes included).
- [The argument in fifteen minutes](https://github.com/NickGillArizona/Duty-Without-Data/blob/main/article/THE_ARGUMENT.md)
  if you want the compressed version first.

## Citable fixed versions

Fixed, citable versions of this archive are its
[tagged GitHub releases](https://github.com/NickGillArizona/Duty-Without-Data/releases); each
release page states what changed. Cite a specific release when you need a version that cannot
move under you.

- [Citation guide](https://github.com/NickGillArizona/Duty-Without-Data/blob/main/CITATION_GUIDE.md)
  — recommended citation forms for the article, the archive, and individual artifacts.
- [CITATION.cff](https://github.com/NickGillArizona/Duty-Without-Data/blob/main/CITATION.cff)
  — machine-readable metadata; GitHub's "Cite this repository" control reads it.

## Reuse terms

Code is MIT licensed. Data and documentation carry the terms stated in the
[licensing guide](https://github.com/NickGillArizona/Duty-Without-Data/blob/main/LICENSING.md),
which also states the manuscript's separate publication-rights posture. Attributions for
third-party materials are in the
[third-party notices](https://github.com/NickGillArizona/Duty-Without-Data/blob/main/THIRD_PARTY_NOTICES.md).

## Corrections

Corrections and questions:
[open an issue](https://github.com/NickGillArizona/Duty-Without-Data/issues) or email
[nickgill@arizona.edu](mailto:nickgill@arizona.edu). Substantive corrections ship as new tagged
releases with their changes stated in the release notes.
